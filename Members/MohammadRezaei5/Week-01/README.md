# FizzBuzz

## Solution

The solution uses a simple iteration approach.

I loop from 1 to n and check each number using the modulo operator (%).

If a number is divisible by both 3 and 5, I add "FizzBuzz".
If it is divisible only by 3, I add "Fizz".
If it is divisible only by 5, I add "Buzz".
Otherwise, I add the number itself.

## Algorithm

- Loop through numbers from 1 to n
- Check divisibility conditions
- Store results in an array

## Data Structure

- Array (List)

## Time Complexity

O(n)

## Space Complexity

O(n)
