# Week 02 — My Solution / راه‌حل من

**Author / نویسنده:** ftmehsm

**Approach / رویکرد:** Binary Search / جستجوی دودویی

## Idea / ایده

در این روش، به‌جای بررسی تک‌تک عناصر آرایه، در هر مرحله وسط محدوده‌ی فعلی را بررسی می‌کنیم.

ابتدا دو متغیر برای مشخص کردن محدوده‌ی جستجو داریم:

* `left` — ابتدای محدوده
* `right` — انتهای محدوده

سپس `mid` را از وسط این محدوده به دست می‌آوریم.

اگر مقدار `nums[mid]` برابر `target` باشد، اندیس آن را برمی‌گردانیم.

اگر `nums[mid]` از `target` بزرگ‌تر باشد، چون آرایه مرتب است، نیمه‌ی سمت راست دیگر نیازی به بررسی ندارد و `right` به قبل از `mid` منتقل می‌شود.

اگر `nums[mid]` از `target` کوچک‌تر باشد، نیمه‌ی سمت چپ حذف می‌شود و `left` به بعد از `mid` منتقل می‌شود.

این روند تا پیدا شدن `target` یا تمام شدن محدوده ادامه پیدا می‌کند.

---

## Complexity / پیچیدگی

* **Time / زمان:** `O(log n)`
* **Space / حافظه:** `O(1)`

در هر مرحله محدوده‌ی جستجو تقریباً نصف می‌شود، بنابراین تعداد بررسی‌ها لگاریتمی است.

از آنجا که آرایه‌ی جدیدی ساخته نمی‌شود و فقط از چند متغیر برای نگهداری محدوده استفاده می‌کنیم، حافظه‌ی اضافی `O(1)` است.
