## Idea

1. First of all take copy of original array
2. Then check whether the middle index of the new array is equal to the target value or not.
3. If true, return its index. Else, check whether the current value is greater than or less than the target, and then decide to discard half of the array.
4. Back to step 2

## Complexity

- Time: O(log n)
- Space: O(1)
