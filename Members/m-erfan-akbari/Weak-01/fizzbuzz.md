## Idea / ایده

### English

In this function, Node.js's readline module is used to receive user input from the terminal.

The input is then validated. If it is valid, the game loop starts, and the player's answers are stored in an array.

### فارسی

در این تابع readline از nodejs استفاده شده تا مقدار ورودی را از ترمینال کاربر دریافت کند.

سپس مقدار ورودی اعبارسنجی می‌شود و در صورت اعتبار حلقه‌ای شروع می‌شود و پاسخ بازی در آرایه ذخیره می‌شود.
