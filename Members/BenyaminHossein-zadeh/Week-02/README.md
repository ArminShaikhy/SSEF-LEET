## Idea / ایده

در این راه‌حل از الگوریتم Binary Search برای پیدا کردن target در یک آرایه‌ی مرتب‌شده استفاده می‌کنیم.

ابتدا دو اشاره‌گر left و right را به ابتدا و انتهای آرایه اختصاص می‌دهیم. سپس تا زمانی که left <= right باشد، عنصر وسط آرایه را بررسی می‌کنیم:

اگر مقدار وسط برابر target باشد، index آن برگردانده می‌شود.
اگر target از مقدار وسط بزرگ‌تر باشد، جستجو را در نیمه‌ی راست ادامه می‌دهیم (left = mid + 1).
اگر target از مقدار وسط کوچک‌تر باشد، جستجو را در نیمه‌ی چپ ادامه می‌دهیم (right = mid - 1).
اگر target در آرایه وجود نداشته باشد، -1 برگردانده می‌شود.

## Complexity / پیچیدگی

- Time / زمان: O(log n) — در هر مرحله، محدوده‌ی جستجو تقریباً نصف می‌شود.
- Space / حافظه: O(1) — فقط از چند متغیر ثابت (left, right, mid) استفاده می‌شود و آرایه‌ی جدیدی ساخته نمی‌شود.
