# Fizz Buzz

## Solution Approach

I solved this problem using a simple `for` loop to iterate through numbers from `1` to `number`.

For each number:

- If it is divisible by both `3` and `5`, I add `"FizzBuzz"` to the result array
- If it is divisible by `3`, I add `"Fizz"`.
- If it is divisible by `5`, I add `"Buzz"`.
- Otherwise, I add the number itself as a string.

Finally, the result array is returned
