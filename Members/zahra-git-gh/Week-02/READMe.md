**Language :** JavaScript 
**Approach :** Binary Search , Iteration , Divide and Conquer

---

## Idea 
The idea is to repeatedly divide the sorted array in half. I compare the target with the middle element and eliminate the half where the target cannot exist. I continue this process until I find the target or the search range becomes empty.


## Complexity 

- Time : O(log n)
- Space : O(1)
