# Week 01 — Fizz Buzz Solution

**Author:** hasanlashgari01  
**Language:** TypeScript  
**Approach:** Iteration + Conditional Statements

---

## Idea

We iterate from 1 to n and check each number.

First, we check if the number is divisible by both 3 and 5 (`i % 15 === 0`) and add `FizzBuzz`.

Then we check divisibility by 3 and 5 separately. If none of the conditions match, we add the number itself as a string.

---

## Complexity

- Time Complexity: `O(n)`
- Space Complexity: `O(n)`
