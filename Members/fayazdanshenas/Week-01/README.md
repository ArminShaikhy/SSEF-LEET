# FizzBuzz Solution

## Approach
برای حل مسئله، اعداد 1 تا n را به ترتیب پیمایش می‌کنم و برای هر عدد با استفاده از عملگر `%` (مدول) بررسی می‌کنم که بر ۳، ۵ یا ۱۵ بخش‌پذیر است. نتیجه را در یک آرایه با اندیس `i-1` ذخیره می‌کنم تا ترتیب اعداد حفظ شود.

ترتیب شرط‌ها به این صورت است:
1. اول `i % 15 === 0` → `"FizzBuzz"`
2. سپس `i % 3 === 0` → `"Fizz"`
3. سپس `i % 5 === 0` → `"Buzz"`
4. در غیر این صورت → `String(i)`

## Algorithm / Data Structure
- **Algorithm**: Linear Traversal (پیمایش خطی)
- **Data Structure**: Array (آرایه)

## Time Complexity
**O(n)** - چون حلقه دقیقاً n بار اجرا می‌شود و هر بار عملیات‌های ثابت (O(1)) انجام می‌دهیم.

## Space Complexity
**O(n)** - برای ذخیره خروجی یک آرایه به اندازه n ایجاد می‌کنیم. (اگر فضای خروجی را محاسبه نکنیم، O(1) خواهد بود)

## Notes
- ترتیب شرط‌ها اهمیت دارد: عدد ۱۵ هم مضرب ۳ است و هم مضرب ۵، پس باید ابتدا شرط `FizzBuzz` بررسی شود تا اشتباه تشخیص داده نشود.
- این راه‌حل ساده‌ترین و مستقیم‌ترین روش برای پیاده‌سازی FizzBuzz است.
